Prompting Engineering & Philosophy

The Veteran's Prompt: Why Depth Multiplies AI

AI code generators are only as good as the software architecture provided to them. Without foundational knowledge, models produce superficial prototypes. With 30 years of systems understanding, they build production engines.

Hardware & Thread-Level Constraints

I don't prompt for a "pixel drawing app"; I specify exact 24×21 matrix byte alignments, 63-byte sprite memory blocks, VIC-II base address pointers ($D000), and cassette buffer addresses ($0340 / 832). When building 3D terrain, I insist on dedicated Web Workers with zero-copy Transferable Float32Array buffers so the UI thread never suffers frame drops.

Mathematical & Algorithmic Rigor

Prompting with mathematical precision unlocks frontier capabilities: instructing Claude to implement stochastic Iterated Function Systems (IFS) for botanical generation, or specifying Turing-complete single-instruction architectures (SUBLEQ) with delta-based output subtraction to prevent screen flicker across 8-bit memory buses.

Immediate Architectural Verification

Having built enterprise databases, ERP synchronizations, and government intranets for decades, I immediately recognize subtle concurrency bottlenecks, memory leaks, and gamut clipping. I guide Claude and Gemini through targeted iterative refactoring, ensuring the generated codebase adheres to production standards.

How Foundational Experience Shapes the Prompt

Typical Generic Prompt
"Make a 3D landscape terrain generator in Three.js where I can move around with my mouse and see mountains and trees."
Result: Single-threaded JavaScript script that freezes the browser while computing simplex noise, crashes on mobile due to unmanaged tree meshes, and lacks atmospheric depth.
Patrick's Architectural Prompt
"Build a browser-based 3D landscape generator inspired by Vista Pro (1991). Run multi-octave simplex terrain in a dedicated Web Worker, passing Float32Array heightmaps and vertex normals to Three.js with zero-copy Transferables. Render up to 35,000 altitude-appropriate trees using GPU instancing, procedural volumetric drifting clouds, and physically positioned sun lighting."
Result: Smooth 60 FPS WebGL application, zero main-thread jank, elevation-accurate biomes, and production-grade Web Worker architecture.
